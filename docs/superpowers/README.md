# Superpowers Workflows (docs/superpowers)

## Responsabilidade do Diretório
Armazena especificações formais de requisitos e planos de execução estruturados para desenvolvimento orientado a specs.

## Estrutura
- `plans/`: Planos de implementação passo a passo.
- `specs/`: Especificações técnicas e arquiteturais de novas funcionalidades.
