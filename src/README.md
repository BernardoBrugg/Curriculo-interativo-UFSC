# Source Layer (src)

## Responsabilidade do Diretório
Contém o código-fonte principal da aplicação frontend e rotas de servidor Next.js para o Currículo Interativo UFSC.

## Estrutura Interna
- `app/`: Páginas, layouts e rotas da API via Next.js App Router.
- `components/`: Componentes visuais e de interação reutilizáveis.
- `hooks/`: Hooks React customizados para gerenciar estado, navegação e interações de drag-and-drop.
- `lib/`: Módulos de lógica de negócios, cálculo de integralização, validação de currículos e integração de dados.
- `types/`: Definições estritas de interfaces e tipos TypeScript do sistema.
- `data/`: Matrizes curriculares normalizadas e indexadas dos cursos da UFSC.
