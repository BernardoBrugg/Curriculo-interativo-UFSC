# API Routes Layer (src/app/api)

## Responsabilidade do Diretório
Centraliza os endpoints de backend (Route Handlers) do Next.js para processar operações seguras no lado do servidor.

## Endpoints
- `auth/`: Manipulação de autenticação e recuperação de credenciais.
- `feedback/`: Recepção e despacho de sugestões e notificações de usuários.
