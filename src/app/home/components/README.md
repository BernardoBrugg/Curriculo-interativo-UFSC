# Home Page Components

## Directory Purpose
Contains presentation widgets for user entry points on the landing page (`/`).

## Components
- **`GuestCourseList.tsx`**: Renders all 9 engineering courses with direct links, enabling zero-friction immediate access for visitors without forcing account registration.
- **`CourseLibrary.tsx`**: Renders the authenticated student's enrolled courses, allowing addition and removal of curricula tied to Firestore.
- **`AuthScreen.tsx`**: Multi-mode authentication form supporting email/password sign-in, account creation, Google popup sign-in, and password recovery.
