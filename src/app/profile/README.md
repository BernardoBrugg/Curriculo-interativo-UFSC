# User Profile Feature (src/app/profile)

## Responsabilidade do Diretório
Fornece a interface e lógica de gerenciamento de perfil do estudante, preferências de exibição e controle de sessão autenticada.

## Componentes
- `page.tsx`: Página principal do perfil do usuário.
- `components/`: Componentes modulares dedicados ao formulário e painéis de dados do usuário.
