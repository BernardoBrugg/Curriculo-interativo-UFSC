# Type Contracts Layer (src/types)

## Responsabilidade do Diretório
Define os contratos de tipos TypeScript do domínio acadêmico, modelando disciplinas, requisitos de integralização, expressões lógicas de pré-requisitos e estado de progresso do estudante.

## Contratos
- `curriculum.ts`: Modelagem canônica de `CurriculumData`, `Course`, `CurriculumCompletion` e `RequirementExpression`.
